Formic 当前模块拓扑

只表示已经实现的职责和依赖方向；字段与错误语义以代码和测试为准。

Formic 负责独立单元执行；调用方负责分片规划和跨单元汇总。完整 input 可用于核实当前单元，不用于 worker 间协调。

作业入口

CLI 与固定配置src/main.rs · src/config.rs
默认读取当前目录 config.toml；--config 可指定文件。合并环境变量后校验计划、续跑身份与输出模式。
→
活动 worker 窗口src/main.rs
默认使用 execution.max_concurrent_units；--concurrency 只显式覆盖本次运行。取得窗口许可后才创建 task；总单元量不设上限。
→
单元循环src/worker.rs
LLM ↔ 工具，多轮直到文本完成、结构化提交、取消或失败。

模型与上下文

稳定输入前缀src/prompt.rs
输出模式 instructions 与任务冻结；user message 只列当前单元文件和分片正文，并说明完整 input 根可用 search/read 搜索核实。
→
三协议适配src/llm/
Completions、Responses、Anthropic 映射为同一消息、工具、usage 和终态。
↔
上下文压缩src/compaction.rs
调用前预算；只压缩完整工具组；内部提交并本地校验。

唯一工具入口

冻结 ToolRegistrysrc/scheduler.rs
稳定名称、schema、来源与执行目标。
→
有界 Schedulersrc/scheduler.rs · src/cache.rs
排队、取消、semaphore、singleflight/LRU、耗时和在途统计。
→
内置只读工具src/tools.rs
search/read；input/output 根；路径与结果边界。
任意自定义 MCPsrc/mcp.rs
stdio 或 Streamable HTTP；启动发现；job/unit 会话；逐 server/tool 限流。

内部终止与持久化

formic_submit_resultsrc/structured.rs
可选作业 schema；worker 截获并本地验证，不进入 Scheduler。
formic_submit_compactionsrc/compaction.rs
只用于压缩摘要，不具备外部能力。
→
输出与可观测性src/output.rs
原子结果、worker 时间线 Markdown、output-schema 与 stats。

取消令牌贯穿 main → worker → LLM/Scheduler → 本地工具或 MCP。metrics 只记录已发生事实，不参与业务准入。
