# 第 5 轮：规模验证（实测驱动）

> 状态：**已完成并验证**（2026-08-07）。本轮是 design §9 的实验轮：mock LLM
> 驱动 5000 worker 全链路，用实测回答——历史体积是否主导内存、调度器集中
> 治理是否成为热点、窗口与历史预算该取什么值。

## 实验设置

- harness：`examples/scale_run.rs`，自生成数据集与计划，内置 mock
  （延迟 20ms、按 `"role":"tool"` 计数识别回合、返回固定 tool call 序列，
  参数按回合交替等价 glob 以规避停滞检测），驱动同 profile 的 formic.exe；
- 参数：units=5000、concurrency=1000、turns=8（每单元 9 次 LLM 调用）、
  协议 completions、debug 构建；每次 search 返回 ~20KB（100 匹配上限内）；
- 指标（`src/metrics.rs`，`FORMIC_METRICS=1` 时每 250ms 一行 stderr）：
  RSS（进程工作集）、llm_in_flight、tool_inflight、history_bytes、
  search 耗时、单元计数；附属证据，不参与业务状态（§9）。

## 实测结果

### 首跑（修复前）

- 5000/5000 全部成功，45000 次请求，退出码 0；墙钟 162.7s（31 单元/秒）；
- **峰值 RSS 1672 MB，峰值 history 仅 203 MB，ΔRSS/Δhistory ≈ 8.05**；
- llm_in_flight 峰值恰为 1000（窗口打满）；tool_inflight 峰值 13；
  search_max_ms 96；
- 曲线形态：history 在 ~200MB 平台期后 RSS 继续爬升，比值随回合数扩大。

### 归因

「历史体积主导内存」的假设**不成立**。真正的主导项是**审计的内存放大**：
每单元审计条目在内存累积到单元结束，而每回合请求体含全量历史，
单单元审计 ≈ Σ回合（本实验 ≈ 640KB），1000 在途 ≈ 640MB，且随回合数
二次增长（history 仅线性）。连接缓冲与请求构造瞬时是次要项。

### 修复（本轮内完成）

`src/output.rs`：`write_audit`（内存累积 Vec 后一次性写）改为
`AuditLog` 流式逐条落盘，创建即建文件，`finish()` 冲刷；写失败仍判单元
失败（证据完整契约不变）；worker 各审计点改为逐条推送。
**审计的磁盘体积不变（完整记录的固有成本），内存放大消除。**

### 对照跑（修复后）

- 5000/5000 全部成功，45000 次请求，退出码 0；墙钟 144.2s（35 单元/秒）；
- **峰值 RSS 852 MB（1672 → 852，放大项消除约 820 MB），峰值 history
  202 MB，ΔRSS/Δhistory ≈ 4.02（8.05 → 4.02）**；
- 曲线形态：RSS 全程跟随 history（中段 history ≈ 156 MB 时 RSS ≈ 650 MB），
  二次发散消失；剩余 ≈ 400–450 MB 固定偏移来自 1000 条连接的缓冲、请求
  构造瞬时与运行时基线——与窗口成比例、有界。

## 规模问题清单与处置

1. **审计内存放大（二次增长）**——本轮修复（流式落盘），对照跑验证；
2. **指标 llm_in_flight 不覆盖响应头等待**——冒烟发现，改为守卫覆盖
   「发送 → 响应头 → 流式正文」全程；
3. **审计磁盘体积** ≈ 3GB/5000 单元（完整记录每次调用输入的固有成本，
   请求体含全量历史）。本轮只记录事实；「首回合全量 + 后续增量」的格式
   压缩是候选优化，需要时另轮评估（§14 完整可复现语义不变）。

## 实测建议值（供后续轮次）

- **窗口默认值语义**：窗口由调用方按配额给出；本实验证明 1000 并发窗口
  在普通开发机上内存可控（修复后对照数据见上）、调度器不成为热点；
- **历史预算**：worker 历史峰值实测 ≈ 8 回合 × 20KB ≈ 160KB/单元；每单元
  历史预算建议取 **2 MB**（≈ 12 倍实测峰值余量），超出即判单元失败
  「历史超出预算」——实现属后续轮次（历史压缩/截断策略届时按此值设计）；
- **search 结果边界**：现值（100 匹配 / 32 KiB / 20 上下文行）在 1000
  并发下未形成热点（tool_inflight ≤ 13、search_max_ms ≤ 96），维持不变。
